# Vichardhara Website

A responsive Hindi-first static website for Vichardhara, designed to work with GitHub Pages.

## Files

- `index.html` — main website
- `css/style.css` — all styling and responsive mobile design
- `js/script.js` — search, category filters and mobile interactions
- `images/logo.jpg` — Vichardhara logo supplied for the project

## Run locally

Just open `index.html` in a browser.

For a better local development experience, use VS Code + Live Server.

## Publish on GitHub Pages

1. Create a new GitHub repository, for example `vichardhara-website`.
2. Upload all files and folders from this project.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

GitHub will give you a Pages URL such as:

`https://YOUR-USERNAME.github.io/vichardhara-website/`

## Before going live

Replace the sample article text and dates with real content.

Also replace `hello@vichardhara.in` in `index.html` with your real email address.

If you later want a real blog/CMS, login, comments, author dashboards or an admin panel, this static version will need a backend or a CMS.
